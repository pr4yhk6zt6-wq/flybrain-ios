# ติดตั้ง .ipa ไม่ผ่าน / ค้างที่ "Installing…" — เช็กลิสต์

เขียนหลังตรวจ `FlyBrain-unsigned-v0.7.ipa` ทีละไฟล์ในซิป (`tools/audit_ipa.py`)

---

## 1. ก่อนอื่น: ตัว `.ipa` เอง "ปกติ" — ตรวจแล้ว

| สิ่งที่ตรวจ | ผล |
|---|---|
| สถาปัตยกรรมไบนารี | **arm64 · platform iOS** (ไม่ใช่ซิมูเลเตอร์/Intel) |
| สิทธิ์ไฟล์ไบนารีในซิป | `-rwxr-xr-x` (0755) ✓ |
| คีย์ใน Info.plist ที่ `installd` ใช้ | ครบ (`CFBundleExecutable`, `CFBundleSupportedPlatforms=iPhoneOS`, `MinimumOSVersion=15.0`, `UIDeviceFamily=[1,2]`, `CFBundleVersion`) |
| ข้อมูลที่แอปต้องเปิด | ครบ (`flybanc.bin`, `flybanc_meta.json`, `World/fly_body.json`, `World/world.json`, `World/fly.bin`) |
| `frames.bin` (ไฟล์บันทึกที่ทำให้ "วีดีโอวิ้ง ๆ") | **ไม่มี** ✓ |
| ไฟล์ซ้ำ byte-identical | **เคยมี!** `World/fly.bin` กับ `World/fly_meshes.bin` = ไฟล์เดียวกัน 6.3 MB → **แก้แล้ว** (ดูข้อ 3) |

⇒ ถ้าไอคอนขึ้นเทาแล้วค้างที่ *Installing…* ปัญหาเกือบทั้งหมดอยู่ที่**ฝั่งเครื่อง/tools** ไม่ใช่ตัวไฟล์

---

## 2. สาเหตุที่พบบ่อยที่สุด (เรียงตามความน่าจะเป็น) และวิธีแก้

### 2.1 ติดตั้งทับของเดิมที่เซ็นด้วยใบรับรองคนละอัน ← อันนี้พบบ่อยสุด
iPhone จะไม่ยอมให้ *ทับ* แอปที่เซ็นด้วย certificate/profile คนละชุด และอาการคือค้างที่ Installing… ตลอด

**แก้**: ลบแอปเดิมออกจากเครื่องก่อน (กดไอคอนค้าง → Remove App → Delete App) **แล้วติดตั้งใหม่** (แอปไม่ได้เก็บข้อมูลอะไรไว้ ไม่เสียหาย)

### 2.2 Low Power Mode (เห็นในภาพของคุณ: แบตเหลือง)
iOS ชะลอ/ชะงักงานติดตั้งเบื้องหลังในโหมดนี้

**แก้**: ปิด Low Power Mode ก่อนติดตั้ง (Settings → Battery → ปิด) แล้วเปิดใหม่หลังติดตั้งเสร็จ

### 2.3 Tool ฝั่งคอมพิวเตอร์ค้าง ไม่ใช่เครื่องค้าง
- **Sideloadly**: ต้องมี Apple Mobile Device Support (iTunes) ที่ใหม่พอ + ตัว Sideloadly ล่าสุด; ถ้าค้างที่ 0% เป็นสิบนาที มักเป็นไดรเวอร์/Anisette
  → ลองปิด-เปิด Sideloadly, ถอดสายเสียบใหม่, ปิด VPN, หรือใช้พอร์ต USB ตรง (ไม่ผ่านฮับ)
- ทางเลือกสำรอง: **AltStore / SideStore** (ต้องมี AltServer บนคอมหรือใช้ SideStore บนเครื่อง)
- **ห้าม** ใช้ Xcode Devices / Apple Configurator / ios-deploy กับ .ipa ที่**ยังไม่ถูกเซ็น** — เครื่องมือพวกนี้จะค้างแบบเดียวกับที่คุณเจอ เพราะมันไม่เซ็นให้

### 2.4 ข้อจำกัดบัญชี Apple ID ฟรี
ฟรี 3 แอป / ใบรับรองอายุ 7 วัน; ถ้าเต็มแล้วจะติดตั้งไม่ผ่าน
**แก้**: ใน Sideloadly/AltStore ลบแอปที่เซ็นไว้เดิมออก (`Revoke Certificates` ในหน้า Settings ของ Sideloadly) แล้วติดตั้งใหม่

### 2.5 อย่า "แตกไฟล์แล้วบีบใหม่"
บน Windows ถ้าแตก `.ipa` ด้วย Explorer แล้ว zip กลับเอง โครงสร้าง `Payload/…` จะเพี้ยน → ค้างที่ติดตั้ง
**แก้**: ส่งไฟล์ `.ipa` ที่ดาวน์โหลดมาให้ Sideloadly **ตรง ๆ** ห้ามเปิด/แตก/เปลี่ยนชื่อ

## 3. สิ่งที่แก้ไปในโค้ดแล้วเพื่อให้ติดตั้งง่ายขึ้น (บิลด์ถัดไป)

1. **ไฟล์ซ้ำ 6.3 MB ถูกถอดออก** — `World/fly.bin` กับ `World/fly_meshes.bin` เป็นไฟล์เดียวกันเป๊ะ (hash ตรงกัน) เพราะสองเครื่องมือต่างคนต่างเขียน "เมช" ของตัวเอง เครื่องเลยต้องคัดลอก 6.3 MB สองรอบตอนติดตั้ง
   → **`.ipa` เล็กลงจาก 19.1 MB → 16.1 MB (−16%), หลังแตกไฟล์ 39.1 → 32.8 MB**
2. **แพ็กด้วย `ditto`** (เครื่องมือของ Apple เอง) แทน `zip -r` — รับประกันสิทธิ์ไฟล์ (executable bit) ในซิป ซึ่งเป็นสาเหตุคลาสสิกของ "ค้างที่ติดตั้ง"
3. **ด่านใหม่ `tools/audit_ipa.py`** เข้า CI แล้ว: ตรวจสถาปัตยกรรม/แพลตฟอร์มของไบนารี, สิทธิ์ไฟล์ในซิป, คีย์ plist, ข้อมูลที่แอปต้องเปิด, ห้ามมี `frames.bin`, และ **ห้ามมีไฟล์ซ้ำเกิน 64 KB** — ถ้าใครทำหลุดอีก บิลด์จะไม่ผ่านทันที (ผมเชื่อมกับเลขเวอร์ชันใน `project.yml` ด้วย เพื่อกันบิลด์ที่เลขเวอร์ชันบนจอไม่ตรงกับของจริง)

**ไฟล์ที่ผมประกอบใหม่ให้ทดสอบทันที** (เนื้อเดียวกันกับบิลด์ CI ทุกไบต์ ยกเว้นไฟล์ซ้ำที่ถอดออก):
`FlyBrain-unsigned-v0.7-lean.ipa` (16.1 MB)

## 4. ลำดับที่แนะนำให้ลอง (ใช้เวลา ~5 นาที)

1. **ลบแอป FlyBrain ออกจากเครื่องก่อน** (สำคัญที่สุด)
2. ปิด Low Power Mode
3. ติดตั้ง `FlyBrain-unsigned-v0.7-lean.ipa` ด้วย Sideloadly (อย่าเปิด/แตกไฟล์ก่อน)
4. เปิดแอป → กด Map → ดูว่ามุมซ้ายบนขึ้น **`v0.7 (7)`** และบรรทัด cord ไม่ใช่ `0.0 Hz` อีก
5. ถ้ายังค้าง: ส่งภาพหน้า "Installing…" + บอกว่าใช้เครื่องมืออะไร เวอร์ชันไหน + iOS เวอร์ชันไหน ผมจะไล่ต่อ

> หมายเหตุ: ทั้งหมดนี้เป็นข้อจำกัดของการเซ็นแอปด้วยบัญชีฟรี ไม่ใช่บั๊กของตัวโปรเจกต์ — และไม่มีอะไรในโปรเจกต์ที่ทำให้ค้างได้ เพราะ `.ipa` ถูกตรวจทีละไฟล์แล้วตามตารางข้อ 1
